# 交付说明（草稿，待效果集评测与质疑签字后定稿）

## 交付范围
核心库（avr-core）、avr-mcp 与 CLI/MCP 入口优化完成；**GUI 未验证**：`App.svelte` 与桌面界面未在 Windows 上手动运行过，只经过 Windows CI 编译、clippy 与测试。

## 做了什么（详见 CHANGELOG 与 ADR 0001–0010）
- P0：固定工具链 1.88 + CI（fmt、clippy -D warnings、测试，Linux 双版本 + Windows）；清零 clippy 与 panic 点；任务锁改用操作系统建议锁；本地文件识别为 `Platform::Local`。
- P1：统一入口 `analyze(ctx, src, opts, deps)`，依赖注入替代全局 JobManager，`Tools` trait 可用假实现测试，错误统一为 `AvrError` + 错误码，MCP 拼装移出核心库。
- P2：转写缓存校验缓存格式与 ASR 内容指纹；流水线去重。P2-1 经核对划掉。
- P3：输出基线快照；MCP 按需读取（摘要索引、`read_transcript` 分页、`get_frame`），`MediaKey` 堵住路径穿越；auto 模式与调用日志（默认关闭）。
- P4-1：中文转写加简体初始提示（进行中）。
- 测试：15 → 51（1.88 下全部通过，2 个按设计 ignore）。

## 行为变化（升级前请看）
- 升级后旧缓存会全部失效，第一次分析会重新处理。
- MCP `analyze_media` 默认仍是 `compact`；`index`、`auto` 需显式指定。
- GUI 返回的错误改为对象（前端读 `e.display`）。
- 本地文件缺 ffmpeg 时到抽音频才报错；会先检查 ASR 配置。
- 中文转写会被推成简体普通话写法，粤语和台湾内容也一样。
- P4-1：语言为 `zh` 时，给 whisper 传简体初始提示「以下是普通话的句子。」（`--prompt`），把输出推向简体（medium/large 模型不加提示时常出繁体）。
  副作用：**粤语、台湾等内容也会被推成简体普通话写法**（粤语口语字、台湾用词/繁体字形会丢失）；需要保留原写法时请把语言设成 `yue` 或 `auto` 等非 `zh` 值。
  ASR 参数修订号并入了转写缓存指纹，**升级后已有的 ASR 转写缓存会再全部失效一次**（音频缓存仍复用）。

## 隐私
- 调用日志默认关闭，`[mcp] call_log = true` 才写 `<data root>/logs/mcp-calls.jsonl`，5MB 轮转；网址只记域名，本地路径只记扩展名。
- **缓存目录本身保存了视频来源和转写全文**。介意的话请定期清理缓存，或把数据目录放在加密盘上。
