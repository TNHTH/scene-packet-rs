# ADR 0009：调用日志只做最低限度脱敏，隐私边界在缓存目录
状态：已采纳（2026-10-11，质疑提出，架构师确认）

背景：P3-3 的 MCP 调用日志 `mcp-calls.jsonl` 记录了 `args` 摘要，含网址与本地路径。讨论过普通哈希、加盐 HMAC（研究员）、对 `media_key` 哈希（架构师）。
决策：
- 文件日志默认关闭，`[mcp] call_log = true` 才写；超过 5MB 改名 `.1` 轮转；stderr 照常输出，绝不写 stdout。
- 网址只记域名，本地路径只记扩展名；不加盐；`media_key` 照常记录。
理由：缓存子目录以 `media_key` 命名，`metadata.json` 存来源网址，`transcript.json` 存全文；能读到日志的人同样能读到缓存，日志深度脱敏没有安全增益，只增加盐文件管理与对照成本。
放弃的备选：加盐 HMAC、`media_key` 哈希（已撤回）。
交付说明须写明：日志记录的字段、位置与开启方式；缓存目录本身保存视频来源与全文，介意者应定期清理缓存或把数据目录放在加密盘上。
