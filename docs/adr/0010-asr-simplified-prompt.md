# ADR 0010：中文转写用简体初始提示（P4-1），标题拼提示推迟（P4-2）
状态：P4-1 已采纳待验收；P4-2 推迟（2026-10-11，架构师）

P4-1：`language=zh` 时给 whisper 传简体初始提示（如"以下是普通话的句子。"），不引入 OpenCC；评测脚本的繁转简保留兜底。
验收：用画面内嵌字幕抄写的参考文本（`/workspace/avr-effect-set/reference/`，360 字，`cer.py`）逐字列出加提示前后差异，并人工逐句检查有无重复或编造。基线：无提示 CER 0.047（字幕删口头语，只作前后对比）。
边界：粤语和台湾内容会被推成简体普通话写法，写入交付说明。

P4-2（推迟）：把视频标题、简介拼进初始提示以纠正领域词。推迟原因：同段视频标题含答案词会高估效果，需另找标题与内容弱相关、带字幕、许可合适的中文视频，并计入"标题误导使转写变差"；收益仅几个错字，优先级低于概要方法与索引模式。

## 修订（2026-10-11）：P4-1 验收不通过，改为转写后繁转简
审查验收（`/workspace/review/p41/`）：同参数下只加 `--prompt "以下是普通话的句子。"`，cns_space 字错误率 0.047 → 0.244；22–64 秒段变好（0.026），138–212 秒段 0.404，漏掉两整句，段数 37 → 30，出现乱码句。
决策：默认不传初始提示词（保留可选开关并写明漏句风险）；繁转简改为转写后用 `zhconv` crate 按字映射，仅 `language=zh` 时做。验收：cns_space 字错误率保持 0.047，输出全为简体。
新增固定指标：凡改动 ASR 参数、提示词或后处理，必须同时报字错误率和漏句数（参考文本里有、转写里整句都没有）；漏句数增加直接打回。
