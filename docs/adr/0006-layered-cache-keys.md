# ADR 0006：缓存键按阶段分层
状态：部分采纳（2026-10-11）——当前只实施最小版本，分层键推迟

背景：`media_key` 只包含输入身份（网址为平台 ID 或规范化网址，本地文件为文件头指纹、大小、时长），不含选项、工具版本和缓存格式版本，换 ASR 模型会命中旧转写。
决策：
- 媒体键 = 输入身份 + `CACHE_SCHEMA`，缓存下载与抽音频结果。
- 帧键 = 媒体键 + 抽帧选项 + ffmpeg 版本。
- 转写键 = 媒体键 + ASR 模型与语言选项 + ASR 版本。
- 选项只取影响输出的字段，固定顺序序列化后哈希；`Tools` trait 增加 `version(ToolId)`，`FakeTools` 返回固定值。
- 结构变化时 `CACHE_SCHEMA` 加一，旧缓存自然失效，不写迁移。
回归测试：换选项不命中；换工具版本不命中；换 ASR 版本后媒体缓存仍命中。
后果：参数调整只重算受影响阶段；首次升级后已有缓存全部失效一次。

## 修订（审查核对后）
- `AnalyzeOptions` 目前为空，抽帧选项未对外暴露，暂无需要分层的选项。
- 现阶段只做：`metadata.json` 写入 `cache_schema` 与 ASR 模型、版本；`load_cached_transcript` 不一致即视为无缓存。
- 回归测试：换 ASR 版本后转写缓存不命中，媒体缓存仍命中。
- 分层键方案保留为后续设计，等真正加入抽帧等影响输出的选项时再实施。
